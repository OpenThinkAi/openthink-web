// how it works

The log is the database. Tables replay from the op log; concurrent edits merge (last-writer-wins fields, label sets, Loro text).

Built to be scripted. pm ready is the work queue; exit 75 means someone else took it.

Sync is optional. A self-hosted hub syncs machines and decides claims first-come. pm app opens a board.
